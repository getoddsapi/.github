## GetOdds

Sports odds API: DraftKings, FanDuel, BetRivers, Pinnacle, PrizePicks, Underdog and Pick6 lines over REST and MCP. Free key, no card.

**Website:** [getoddsapi.com](https://getoddsapi.com) · **Docs:** [getoddsapi.com/docs](https://getoddsapi.com/docs) · **Free key:** [getoddsapi.com](https://getoddsapi.com)

### Install

```bash
pip install getodds
npm install getoddsapi
npx -y getodds-mcp   # MCP server for Claude, Cursor and ChatGPT
```
